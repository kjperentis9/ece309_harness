# C Command-Line Harness

This project is a simple command-line program written in C.

The program repeatedly asks the user for input. If the input contains "hello,"
it prints a hardcoded greeting. If the user enters "exit," the program ends.
Any other input is echoed back to the user.

## Compile the Program

```bash
gcc harness.c -o harness
